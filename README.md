Проект: образовательный веб‑квест «Проект Генезис» (7 класс)
Интерактивный веб‑квест по информатике для 7 класса (базовый уровень) на тему:
«Компьютер — универсальное устройство обработки данных».

Квест рассчитан на одно занятие (40 минут) и построен как ролевая командная работа: 
каждый ученик выполняет задания своей роли, получает результат в формате JSON, после чего команда собирает общий продукт — инфографику (чертаж) и запускает сюжетный финал «восстановление памяти суперкомпьютера».

Для кого:
учителя информатики (7 класс, базовый уровень)
студенты пед. направлений / авторы методических разработок
для проведения урока в компьютерном классе

Что внутри: 
сюжетная легенда и выбор команд/ролей
4 роли и интерактивные задания (drag&drop, проверка с исправлением ошибок)
экспорт результатов каждой роли в .json
финальная сборка инфографики из 4 JSON‑модулей + анимация завершения
итоговый продукт можно скачать как PNG

Как запустить:
Склонируйте репозиторий.
Откройте файл index.html в любом современном браузере.
Для корректной работы сохранения скриншотов убедитесь, что библиотека html2canvas.min.js находится в корневой папке проекта.

Образовательные результаты (по ФРП):
работа с компонентами ПК (процессор, ОЗУ, ПЗУ, устройства ввода‑вывода)
понимание этапов развития ЭВМ
примеры устройств хранения/передачи информации
соотнесение характеристик компьютера с задачами

Технологии:
HTML + CSS + JavaScript (без серверной части).
Работает локально в браузере.
